## ✨ Featured Projects

### 🔹 Job Aggregation ETL Pipeline using PySpark and Databricks
Built an end-to-end ETL pipeline in Databricks to ingest and process **100+ job listings from SerpApi** using PySpark.

**Highlights:**
- Designed a **3-layer Medallion Architecture**
- Built Bronze, Silver, and Gold layers
- Applied deduplication, null handling, and schema standardization
- Generated structured datasets for hiring roles, companies, and location insights

**Tech Used:**  
`Python` `PySpark` `Apache Spark` `Spark SQL` `Databricks` `SerpApi`
